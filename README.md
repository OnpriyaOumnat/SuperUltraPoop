# SuperUltraPoop (PHP + MySQL)

## ติดตั้ง
1. ติดตั้ง XAMPP (PHP 8+) แล้วเปิด **Apache** และ **MySQL** ใน XAMPP Control Panel
2. คัดลอกโฟลเดอร์ `SuperUltraPoop` ไปไว้ที่ `C:\xampp\htdocs\SuperUltraPoop`
3. เปิด http://localhost/phpmyadmin → แท็บ **Import** → เลือก `database/superultrapoop.sql` → Go
   (ไฟล์จะสร้างฐานข้อมูล `superultrapoop` ให้เอง)
4. ฐานข้อมูลที่นำเข้าจากไฟล์ `superultrapoop.sql` เวอร์ชันปัจจุบันมีคอลัมน์ติดตามการโอนและวันที่รับชำระอยู่แล้ว หากใช้ฐานข้อมูลเดิม ให้นำเข้า migration ที่ยังขาด; สำหรับการแนบสลิป ให้นำเข้า `database/add_transfer_slip.sql` หนึ่งครั้ง
5. เปิดโฟลเดอร์ด้วย VS Code (File → Open Folder) แล้วแก้ `config/database.php` ถ้า MySQL ของคุณมีรหัสผ่าน
6. ใส่รูปสินค้าในโฟลเดอร์ `assets/images/` ตามชื่อไฟล์ใน SQL (เช่น `melon-bread-queen.jpg`)
   หรืออัปโหลดผ่านหลังบ้าน — ถ้าไม่มีรูปจะแสดง placeholder อัตโนมัติ

## ใช้งาน
- หน้าร้าน: http://localhost/SuperUltraPoop/
- หลังบ้าน: http://localhost/SuperUltraPoop/admin/login.php
- ถ้ายังไม่มีบัญชีในตาราง `admins` หน้า Login จะแสดงปุ่มสร้างแอดมินคนแรก และปิดการสมัครทันทีเมื่อสร้างสำเร็จ
- เพิ่มบัญชีแอดมิน: เข้าสู่ระบบหลังบ้าน แล้วเลือก **จัดการแอดมิน** (เฉพาะแอดมินที่ล็อกอินแล้ว)
- หลังบ้านใช้ชุดเดียวที่ `/admin/` สำหรับ Dashboard, Products, Orders, สมาชิก และจัดการแอดมิน
- จัดการสินค้า: เลือก **Products** หรือ **สินค้าทั้งหมด** ใน Dashboard เพื่อดู เพิ่ม แก้ไข และลบสินค้า
- สถานะคำสั่งซื้อ: Pending → Paid → Processing → Shipped → Completed; แอดมินตรวจสอบสถานะและการโอนในรายละเอียดคำสั่งซื้อ และยกเลิกได้ก่อนจัดส่ง (ระบบคืนสต็อกครั้งเดียว)
- URL เก่าภายใต้ `/user/` จะเปลี่ยนเส้นทางไปหน้าที่ตรงกันใน `/admin/` เพื่อรองรับ bookmark เดิม โดยไม่มีหน้าหลังบ้านแยกชุด
- แอดมินเริ่มต้น: `admin` / `Admin@12345` → **ต้องเปลี่ยนรหัสผ่านหลังติดตั้ง**
  (สร้าง hash ใหม่: `php -r "echo password_hash('รหัสใหม่', PASSWORD_DEFAULT);"` แล้วอัปเดตตาราง `admins` ใน phpMyAdmin)

## วิธีทดสอบ
1. หน้า Products: กด All Products (15) / Bakery (9) / Angelanimal (6) ตัวเลขดึงจากฐานข้อมูล
2. เพิ่มสินค้าลงตะกร้า → สลับหมวด → ตะกร้าต้องไม่หาย
3. กด Checkout โดยยังไม่เข้าสู่ระบบ → เข้าสู่ระบบหรือสมัครสมาชิก → กลับไป Checkout และยืนยันคำสั่งซื้อ → ได้เลขคำสั่งซื้อ → ดูที่ Track Order
4. หลังบ้าน: เพิ่ม/แก้/ลบสินค้า, เปลี่ยนสถานะคำสั่งซื้อ, ยกเลิกออเดอร์ (สต็อกถูกคืนครั้งเดียว)

## หมายเหตุ
- การโอนเงินใช้ QR ใน `image/QRcode.png` ลูกค้าแจ้งยอดและแนบสลิปโอนเงิน แล้วแอดมินตรวจสอบรายการเดินบัญชีก่อนตั้งสถานะเป็น Paid; QR ไม่ได้เชื่อมต่อธนาคารเพื่อตรวจเงินเข้าอัตโนมัติ
- ค่าตั้งค่าร้านค้าอยู่ในตาราง `store_settings` และแก้ผ่าน phpMyAdmin
